# 🏁 CAR RACING

Oddiy brauzer poyga o‘yini. HTML, CSS va JavaScript yordamida yaratilgan.

## O‘ynash
- **Kompyuter:** klaviaturadagi chap/o‘ng strelkalar.
- **Telefon:** ekrandagi chap/o‘ng tugmalar.
- Boshqa mashinalarga tegmasdan ochko to‘plang.

## GitHub Pages
Loyiha GitHub Actions orqali deploy qilinadi. Repository → **Settings → Pages** bo‘limida **Source: GitHub Actions** tanlang. Shundan so‘ng `main` branchga har bir push avtomatik deploy qiladi.
